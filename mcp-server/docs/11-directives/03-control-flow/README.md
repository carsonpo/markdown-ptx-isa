# 11.3. Control Flow Directives

PTX provides directives for specifying potential targets for `brx.idx` and `call` instructions. See the descriptions of [brx.idx](../../09-instruction-set/14-control-flow/brx-idx.md) and [call](../../09-instruction-set/14-control-flow/call.md) for more information.

- `.branchtargets`
- `.calltargets`
- `.callprototype`

## Pages

- [11.3.1. Control Flow Directives: .branchtargets](branchtargets.md) — declare a list of potential branch targets for `brx.idx`.
- [11.3.2. Control Flow Directives: .calltargets](calltargets.md) — declare a list of potential call targets for an indirect call.
- [11.3.3. Control Flow Directives: .callprototype](callprototype.md) — declare a prototype for use in an indirect call.
