# 11.8. Miscellaneous Directives

PTX provides the following miscellaneous directives:

- `.blocksareclusters`
- `.language`

## Pages

- [11.8.1. Miscellaneous Directives: .blocksareclusters](blocksareclusters.md) — Specify that CUDA thread blocks are mapped to clusters.
- [11.8.2. Miscellaneous Directives: .language](language.md) — Specify the source language(s) used to generate the kernel or function.
