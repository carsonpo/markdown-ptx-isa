# 11.1. PTX Module Directives

The following directives declare the PTX ISA version of the code in the module, the target architecture for which the code was generated, and the size of addresses within the PTX module.

- `.version`
- `.target`
- `.address_size`

## Pages

- [11.1.1. PTX Module Directives: .version](version.md) — PTX ISA version number of the module.
- [11.1.2. PTX Module Directives: .target](target.md) — architecture and platform target, with the per-target feature tables.
- [11.1.3. PTX Module Directives: .address_size](address_size.md) — address size (32 or 64 bits) used throughout the module.
