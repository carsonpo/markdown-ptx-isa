# 12. Descriptions of .pragma Strings

This section describes the `.pragma` strings defined by `ptxas`.

## Pages

- [12.1. Pragma Strings: "nounroll"](nounroll.md) — Disable loop unrolling in the optimizing backend compiler.
- [12.2. Pragma Strings: "used_bytes_mask"](used_bytes_mask.md) — Mask indicating which bytes of a load's data are used.
- [12.3. Pragma Strings: "enable_smem_spilling"](enable_smem_spilling.md) — Enable register spilling into shared memory for a function.
- [12.4. Pragma Strings: "frequency"](frequency.md) — Hint the execution frequency of a basic block.
- [12.5. Pragma Strings: "mma_throughput"](mma_throughput.md) — Enable compiler loop optimizations for `mma` operations.
