# 9.7.8. Half Precision Comparison Instructions

The comparison instructions are:

- `set`
- `setp`

## Pages

- [9.7.8.1. Half Precision Comparison Instructions: set](set.md) — Compare `.f16`, `.bf16`, `.f16x2` or `.bf16x2` values and write an integer or floating-point result register.
- [9.7.8.2. Half Precision Comparison Instructions: setp](setp.md) — Compare `.f16`, `.bf16`, `.f16x2` or `.bf16x2` values and write the result to one or two predicate registers.
