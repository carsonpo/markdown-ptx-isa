# 9.7.21. Miscellaneous Instructions

The Miscellaneous instructions are:

- `brkpt`
- `nanosleep`
- `pmevent`
- `trap`
- `setmaxnreg`

## Pages

- [9.7.21.1. Miscellaneous Instructions: brkpt](brkpt.md) — breakpoint; suspends execution.
- [9.7.21.2. Miscellaneous Instructions: nanosleep](nanosleep.md) — suspend the thread for an approximate delay given in nanoseconds.
- [9.7.21.3. Miscellaneous Instructions: pmevent](pmevent.md) — trigger one or more performance monitor events.
- [9.7.21.4. Miscellaneous Instructions: trap](trap.md) — abort execution and generate an interrupt to the host CPU.
- [9.7.21.5. Miscellaneous Instructions: setmaxnreg](setmaxnreg.md) — hint to change the number of registers owned by the warp.
