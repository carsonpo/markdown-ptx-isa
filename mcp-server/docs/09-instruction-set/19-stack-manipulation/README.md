# 9.7.19. Stack Manipulation Instructions

The stack manipulation instructions can be used to dynamically allocate and deallocate memory on the stack frame of the current function.

The stack manipulation instructions are:

- `stacksave`
- `stackrestore`
- `alloca`

## Pages

- [9.7.19.1. Stack Manipulation Instructions: stacksave](stacksave.md) — save the value of the stack pointer into a register.
- [9.7.19.2. Stack Manipulation Instructions: stackrestore](stackrestore.md) — update the stack pointer with a new value.
- [9.7.19.3. Stack Manipulation Instructions: alloca](alloca.md) — dynamically allocate memory on the stack.
